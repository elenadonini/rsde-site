# RSDE – Remote Sensing for Digital Earth

Website of the RSDE research unit (Digital Society Center, Fondazione Bruno Kessler).

- `index.html` – the whole site (one page, no build step)
- `img/` – images (run `./scarica_immagini.sh` once to download them from the current site)
- People and publications are edited in the `PEOPLE`, `FORMER` and `PUBS` lists at the bottom of `index.html`.

Published with GitHub Pages.

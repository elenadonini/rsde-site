# RSDE – Remote Sensing for Digital Earth

Website of the RSDE research unit (Digital Society Center, Fondazione Bruno Kessler). Static site, no build step: published with GitHub Pages.

| File | What it is |
|---|---|
| `index.html` | Home page (all sections) |
| `gallery.html` | Photo gallery of the group |
| `style.css` | Shared styles |
| `img/` | Images (run `./scarica_immagini.sh` once to download them from the current site) |
| `img/gallery/` | Put group photos here |

## How to update
- **People** (bio, links, photo): `PEOPLE` list at the bottom of `index.html`.
  Links available: `email`, `scholar`, `website`, `linkedin`, `researchgate`, `orcid`, `github`.
- **Publications**: `PUBS` list at the bottom of `index.html`.
- **Gallery**: copy the photo into `img/gallery/` and add a line to `PHOTOS` at the bottom of `gallery.html`.
